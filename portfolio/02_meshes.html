Project Procedural Geometric Modeling

3D Graphics

Project Overview

Procedural Geometric Modeling is the second assignment for CS250 Computer Graphics II. The goal is to procedurally generate six 3D primitives — Plane, Cube, Sphere, Torus, Cylinder, and Cone — entirely through code, without importing any external model files. Each mesh is constructed by computing vertex positions, normals, and UV coordinates from parametric equations, then assembling triangle index buffers to form the final geometry. The project also introduces a Material system for managing shaders, textures, and render state, and supports wireframe and normal visualization modes.

Tasks Completed

  • Index Buffer Generation: Implemented a shared index buffer builder that creates triangle pairs per grid cell from stacks and slices parameters, reused across all mesh types.
  • Plane: Generated a grid of vertices spanning [-0.5, 0.5] in X and Y with Z-facing normals and direct UV mapping.
  • Cube: Constructed by transforming six instances of the plane geometry with rotation and translation matrices for each face.
  • Sphere: Computed vertices using spherical coordinates (latitude/longitude) with radius 0.5, deriving normals from normalized positions.
  • Torus: Generated using two-angle parametric equations with major radius 0.35 and minor radius 0.15, computing normals as the offset from the tube center.
  • Cylinder: Built the side surface with circular cross-sections along the Y axis, plus top and bottom caps using a fan triangle pattern.
  • Cone: Created with linearly tapering radius from bottom to top, computing surface normals using the tangent slope, with a bottom cap.
  • Wireframe Conversion: Implemented conversion from triangle indices to line indices, extracting quad outlines where possible and falling back to triangle edges for caps.

Reflection

This assignment deepened my understanding of how 3D meshes are built from mathematical definitions rather than artist-created models. The trickiest part was getting the cap geometry right for cylinders and cones — the winding order of the triangles had to be flipped depending on whether it was a top or bottom cap to ensure correct face culling. The wireframe conversion logic was also interesting, as it needed to detect the quad pattern from the index buffer to avoid drawing redundant diagonal edges. Seeing all six shapes rotate together with proper UV mapping and normals was very satisfying and gave me a solid feel for how parametric surfaces work in practice.
