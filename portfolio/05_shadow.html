Project Shadow Mapping

3D Graphics

Project Overview

This project implements real-time shadow mapping for a 3D scene rendered with OpenGL (ES 3.0 / WebGL 2). A perspective light source casts shadows onto dynamically placed objects by rendering a depth map from the light's point of view, then comparing fragment depths during the main rendering pass. The demo also features exponential fog, gamma correction, and an interactive ImGui panel for tuning every shadow parameter at runtime.

Tasks Completed

  • Camera System — Implemented ViewMatrix() and ToWorldMatrix() using the camera's orthonormal basis vectors (Right, Up, Back) and eye position, without relying on external inverse functions.
  • Texture Enhancements — Extended the Texture class with LoadAsDepthTexture() supporting 16/24/32-bit depth formats with shadow comparison mode, and LoadAsRGBA() for color render targets.
  • FrameBuffer Class — Built a framebuffer abstraction that creates and manages depth and color texture attachments, with proper OpenGL resource lifecycle handling.
  • Shadow Mapping Pipeline — Implemented a two-pass rendering pipeline: first rendering scene depth from the light's perspective into an FBO, then sampling that depth map in the main pass using textureProj() with a bias matrix for correct shadow lookup.
  • Shader Work — Wrote the shadow vertex shader to transform positions into clip, view, and shadow space, and the fragment shader to perform projective shadow sampling, behind-light correction, gamma correction (1/2.2), and exponential fog blending.
  • Debug Visualization — Added light frustum rendering by transforming an NDC cube through the inverse light projection and the light's camera-to-world matrix, plus a full-screen depth texture preview.

Reflection

The trickiest part was getting the shadow bias matrix right — the scale-and-translate from NDC [-1,1] to texture coordinates [0,1] is a subtle but critical step that causes visible artifacts when wrong. Polygon offset and the option to render back faces during the depth pass helped reduce shadow acne. Understanding how textureProj() divides by w internally made the projective texture lookup click. Overall, this project tied together framebuffers, multiple render passes, and coordinate-space transformations in a way that solidified my understanding of the graphics pipeline.
