Project Value Noise

3D Graphics

Project Overview

This project implements a Value Noise algorithm in C++ for generating procedural textures. The system supports 1D, 2D, and 3D noise evaluation using permutation hashing and configurable interpolation methods (Linear, Cosine, Smoothstep, Quintic). The generated noise is uploaded to an OpenGL texture and displayed in real time, with ImGui controls for adjusting period size, smoothing, tiling scale, noise dimension, and pattern type (Fractal Sum, Turbulence, Marble, Wood).

Tasks Completed

  • Value Noise Core — Implemented the ValueNoise template class with 1D linear, 2D bilinear, and 3D trilinear interpolation, all driven by a permutation hash table that wraps at period boundaries for seamless tiling.
  • Permutation Hash — Built a PermutationHash class that generates a shuffled permutation table at construction and supports 1D, 2D, and 3D index lookups using bitwise masking for period wrapping.
  • Interpolation & Smoothing — Implemented linear_mix, bilinear_mix, and trilinear_mix functions alongside four fade curves (Linear, Cosine, Smoothstep, Quintic) for controlling interpolation smoothness.
  • Noise Coordinate System — Created make_noise_coord to decompose floating-point input into base index, next index, and fractional interpolant.
  • Texture Pipeline — Added UploadAsRGBA to the Texture class using TexSubImage2D for efficient pixel data updates without recreating the texture.
  • Shaders — Wrote simple.vert and simple.frag for full-screen quad rendering with configurable tile scaling via a uniform.

Reflection

Getting seamless tiling right was the key challenge — the permutation hash must wrap consistently at period boundaries so that noise values at opposite edges match up. Using bitwise AND with the period mask made this clean and efficient. Implementing the four different smoothing methods side by side gave a clear intuition for how interpolation curves affect visual quality: linear produces visible grid artifacts, while quintic smoothing eliminates them almost entirely.
