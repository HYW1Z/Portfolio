Project Hello Quad

3D Graphics

Project Overview

Hello Quad is the first assignment for CS250 Computer Graphics II at DigiPen Institute of Technology. The goal of this project is to set up a foundational OpenGL rendering pipeline capable of displaying and animating a textured quad. This includes implementing core OpenGL abstraction classes (IndexBuffer, VertexBuffer, VertexArray, and Texture), writing GLSL shaders with time-based animations, and building a cross-platform application that runs on both Windows x64 and the Web via Emscripten/WebGL 2.

Tasks Completed

  • IndexBuffer: Implemented GPU index buffer creation, binding, and cleanup using GL:: wrapper functions with support for unsigned int, unsigned short, and unsigned byte element types.
  • VertexBuffer: Implemented GPU vertex buffer allocation with both static and dynamic data upload via BufferData and BufferSubData, along with proper resource management through move semantics.
  • VertexArray: Implemented vertex array object creation with automatic vertex attribute configuration, supporting interleaved buffer layouts, integer/float attribute pointers, normalization, and instancing divisors.
  • Texture: Implemented 2D texture loading from file images (via stb_image) and from memory, with configurable filtering (Nearest/Linear) and wrapping modes (Repeat, Clamp, Mirror).
  • Vertex Shader Animation: Added time-based rotation and a breathing scale effect to animate the quad vertices using the uTime uniform from the application's elapsed time.
  • Fragment Shader Animation: Implemented a smooth cycling blend between vertex colors and texture colors using a sine-wave mix factor driven by uTime.
  • Custom Texture: Created a custom paint_me.png texture with an original drawing.
  • Environment Integration: Connected shader uniforms (uTime, uFrameCount) to the window environment variables (ElapsedTime, FrameCount, FPS) for real-time animation control.

Reflection

This project served as a solid introduction to setting up a modern OpenGL rendering pipeline from scratch. One of the key challenges was understanding how Vertex Array Objects coordinate the relationship between vertex buffers, index buffers, and attribute pointers — particularly ensuring the correct bind/unbind order so that the VAO properly records the element buffer binding. Working with the GL:: wrapper functions instead of raw OpenGL calls helped reinforce good error-checking habits. Writing the shader animations was the most rewarding part, as small changes in the GLSL code produced immediately visible results, and the hot-reload feature made iteration fast and enjoyable. Overall, this assignment built a strong foundation for the more advanced rendering techniques to come in later assignments.
